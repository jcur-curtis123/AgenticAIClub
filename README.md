# AgenticAIClub

The official repository of the **Agentic AI Club at the Roux Institute, Northeastern University** (Portland, Maine). We learn, build, and share AI agents: systems that plan, use tools, and take action.


## Getting Started

```bash
git clone https://github.com/<org-or-username>/AgenticAIClub.git
cd AgenticAIClub
python -m venv .venv && source .venv/bin/activate
```

## Contributing

1. Create a branch: `git checkout -b your-topic`
2. Add your work, with a `README.md` in any new folder
3. Open a pull request

New to Git? Ask in the chat and we'll help with your first PR.
